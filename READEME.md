# 🩺 Vitta — Clínica Pediátrica

Site institucional desenvolvido para uma clínica pediátrica fictícia como projeto acadêmico.

O projeto apresenta informações sobre a clínica, serviços, especialidades, contato e uma página de agendamento, buscando oferecer uma experiência simples, organizada e acessível aos usuários.

---

## 📋 Sobre o projeto

O Vitta foi desenvolvido com o objetivo de criar a interface de um site institucional para uma clínica especializada em atendimento pediátrico.

O projeto foi pensado para apresentar as informações da clínica de forma clara, utilizando uma identidade visual voltada ao público infantil e recursos de interação para facilitar a navegação.

O site possui foco em **desktop**.

---

## ✨ Funcionalidades

- 🏠 Página inicial com apresentação da clínica
- 🩺 Seção de serviços oferecidos
- 👶 Seção de especialidades pediátricas
- 📅 Página de agendamento
- 🔗 Acesso ao agendamento diretamente pelas especialidades
- 📞 Página de contato
- 📍 Localização através do Google Maps
- ✅ Validação dos campos do formulário
- ♿ Integração com o VLibras para acessibilidade
- 🖼️ Imagens otimizadas para melhor desempenho
- 🧭 Navegação entre páginas e seções

---

## 🛠️ Tecnologias utilizadas

- HTML5

- JavaScript
- Google Maps
